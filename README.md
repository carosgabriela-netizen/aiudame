# Suizo Guía Inteligente

creame un aplicatión móvil que ayude a resolver preguntas de una escuela llamada I.E Peruano Suizo con los colores rojo y blanco predominando mas el blanco, quiero que inclua ML,DL e IA generativa y que estos no te den la respuesta pero te den pistas para guiar el aprendizaje de los estudiantes. que te den 3 o 5 pistas que facilitenla obtencion de la respuestas y que esten divididas entre primaria y secundaria y que estos tengan distinta forma de ayudarte es decir que en secundaria usaran textos un poco mejor adaptados para su edad, quiero que que el sistema ajuste el tono pedagógico según el nivel escolar seleccionado. y tenga una base de datos con el contenido del ministerio, el contenido de lo mandare por link para que ayude al momento de dar las respuestas. este es el link: https://materialeducativoperu.com/
Asegúrate de que el bot priorice siempre la precisión pedagógica según esos recursos.
